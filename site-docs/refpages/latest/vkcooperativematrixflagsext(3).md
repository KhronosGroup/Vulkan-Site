VkCooperativeMatrixFlagsEXT - Bitmask of VkCooperativeMatrixFlagBitsEXT

// Provided by VK_EXT_cooperative_matrix_maintenance1
typedef VkFlags VkCooperativeMatrixFlagsEXT;

[VkCooperativeMatrixFlagsEXT](#) is a bitmask type for setting a mask of
zero or more [VkCooperativeMatrixFlagBitsEXT](VkCooperativeMatrixFlagBitsEXT.html).
